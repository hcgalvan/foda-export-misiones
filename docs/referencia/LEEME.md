# Excel de referencia

Copiar acá, desde tu disco local, los dos archivos originales:

- `FODA_Export_Misiones_2026_DEMO.xlsx` — plantilla con datos ficticios de ejemplo (aserradero de Eldorado) ya cargados. Es la **fuente de verdad del cálculo** mientras no exista un test de paridad automatizado (Fase 2 del plan de trabajo): si el motor en JavaScript/Python difiere de este archivo, el Excel manda.
- `FODA_Export_Misiones_2026.xlsx` — plantilla en blanco, sin datos.

Ambos se versionan en el repositorio porque son el instrumento original y la referencia contra la que se valida el software — no son datos de ninguna pyme real.
